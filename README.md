Число логических процессоров не означает, что в процессоре ровно столько же физических ядер. В Диспетчере задач есть отдельная строка Ядра, которая показывает физические ядра. У современных процессоров одно физическое ядро показывается системе как два логических. Поэтому логических процессоров обычно в 2 раза больше, чем физических ядер. Значения не совпадают, физических ядер меньше.
